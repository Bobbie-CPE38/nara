## งานจริง แยกตามคน

### คน 1 (คุณ)

- **PR 0:** Contract คือเอกสาร + `transitions.py` + เทสต์ ต้องเข้าก่อนทุกคน
- **PR 1b:** Seam จาก Gap ไป Solver
- **PR 5:** หน้า `approvals` ให้ปุ่ม Reject ใช้งานจริง

### คน 2

- **PR 1a:** ตัวตรวจ Hard Rules
- **PR 2a:** Solver ใช้ Hard Rules กับ Gap และกรณีไม่ได้ผู้สมัคร
- **PR 3:** Safety บันทึกผลไม่ผ่านแล้วไปคนถัดไป
- **PR 6:** หน้า `cases/[id]`

### คน 3

- **PR 2b:** เลือกคนถัดไป + Reject + หน้า `line-sim`
- **PR 4:** ไม่อนุมัติ

### ยังไม่มีเจ้าของ

- **PR 1c:** ย้ายกฎ "มี Offer ค้าง" เป็นของกลาง ขึ้นกับคำตอบของ Q4

## ลำดับที่ต้องเกิด

1. คุย Q1 ถึง Q10 ทั้งสามคน ถ้ายังไม่ได้คำตอบ คุณเปิด PR 0 ไม่ได้ เพราะไม่รู้ว่าต้องเขียน Transition กับ Seam แบบไหน
2. คุณเปิด PR 0 ทุกคนรีวิว
3. ทั้งสามคนเริ่มขนานกัน หลัง PR 0 เข้า
4. Q11 ถึง Q20 คุยระหว่างทางได้ แต่ละข้อขวางแค่ PR ของคนที่อยู่ในคอลัมน์ "ขวางใคร"

> **ข้อควรรู้:** การแบ่งคนในข้อ 10 เป็นข้อเสนอของผมตามเจ้าของไฟล์เดิม ถ้าดูแล้วไม่ balance ปรับได้ ตอนนี้คน 2 ได้ 4 PR ซึ่งมากสุด
